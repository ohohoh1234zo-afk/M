# Phone Guard (Android) — รุ่นต้นแบบ 1.0

แอป Android ต้นแบบสำหรับตรวจจับการเคลื่อนไหวของโทรศัพท์และส่งเสียงเตือน

## ฟังก์ชันที่ตั้งใจไว้
- เปิดระบบป้องกันและหน่วงเวลา 10 วินาที
- ตรวจจับการเคลื่อนไหวด้วย accelerometer
- เสียงเตือนและสั่นเมื่อพบการเคลื่อนไหว
- ปิดระบบผ่าน PIN (ค่าเริ่มต้น `1234`)
- เปลี่ยน PIN ได้จากหน้าหลัก
- ใช้ Foreground Service เพื่อช่วยทำงานขณะหน้าจอดับ

## สร้าง APK ผ่าน GitHub Actions
โครงการนี้ยังไม่มีไฟล์ APK ที่คอมไพล์แล้วแนบมาด้วย วิธีนี้ต้องมีบัญชี GitHub และอัปโหลดไฟล์โครงการทั้งหมดเข้า repository:
1. สร้าง repository ใหม่บน GitHub
2. อัปโหลดเนื้อหาทั้งหมดในโฟลเดอร์ `PhoneGuard` เข้า root ของ repository โดยต้องรวมโฟลเดอร์ `.github/workflows` ด้วย
3. เปิดแท็บ **Actions** และเปิดใช้งาน workflow หาก GitHub ขออนุญาต
4. เลือก **Build Phone Guard APK** แล้วกด **Run workflow**
5. เมื่อทำงานสำเร็จ เปิดรายการ workflow run นั้น แล้วดาวน์โหลด artifact ชื่อ `PhoneGuard-debug-apk`
6. แตกไฟล์ ZIP artifact แล้วติดตั้ง `app-debug.apk` บน Android โดยอนุญาตการติดตั้งจากแหล่งที่ใช้เปิดไฟล์ หากระบบถาม

Workflow ใช้ JDK 17, Gradle 8.9 และ Android SDK 35 ตามข้อกำหนดของ Android Gradle Plugin 8.7.3

## วิธีใช้
1. เปิด Phone Guard
2. เปลี่ยน PIN เริ่มต้น `1234` ก่อนใช้งาน
3. วางโทรศัพท์บนพื้นผิวมั่นคง
4. กด **เปิดระบบป้องกัน** แล้วรอ 10 วินาที
5. เมื่อโทรศัพท์ถูกยกหรือขยับแรง แอปอาจส่งเสียงเตือน
6. เปิดแอป กด **ปิดระบบ / หยุดเสียงเตือน** แล้วใส่ PIN

## ข้อจำกัดสำคัญ
- โค้ดนี้เป็นต้นแบบ ยังไม่ได้คอมไพล์หรือทดสอบบนโทรศัพท์จริง
- การตรวจจับจาก accelerometer อาจเตือนผิดจากแรงสั่นหรือไม่จับการยกที่นุ่มมาก
- Android บางยี่ห้ออาจจำกัดการทำงานเบื้องหลัง ต้องตรวจการตั้งค่าแบตเตอรี่ด้วย
- PIN เก็บด้วย SharedPreferences แบบพื้นฐาน ไม่ใช่ระบบรักษาความปลอดภัยระดับสูง
- แอปไม่สามารถยืนยันว่าใครเป็นผู้หยิบ และไม่รับประกันการทำงานหลังถูกบังคับหยุดหรือรีสตาร์ตเครื่อง
